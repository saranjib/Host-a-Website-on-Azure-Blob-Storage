AZURE CLOUD PROJECT

Website Hosted on Azure Blob Storage

A static website deployed to Microsoft Azure Blob Storage using Terraform and GitHub Actions.

About This Project

This project demonstrates how to host a static website using Azure Blob Storage.

☁️ Azure

Microsoft Azure provides the cloud infrastructure.

📦 Blob Storage

Azure Blob Storage hosts the website files.

⚙️ Terraform

Infrastructure is created using Infrastructure as Code.

🔄 GitHub Actions

Website deployment is automated through CI/CD.
